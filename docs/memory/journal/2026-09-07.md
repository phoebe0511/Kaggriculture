## §93 advantage 本身是好的 learning signal

`--dump-batch` 存的 60 批（`phi-gt`，從 ckpt-00140 接著跑 60 輪），
690,240 個 decision、960 條軌跡。

### 93.1 更新方向 vs advantage

```
                        原始 adv    全批置中後
adv>0 且 Δlogp>0          79.7%       81.2%
adv<0 且 Δlogp<0          83.9%       85.3%
整體方向一致率             81.7%       83.1%
平均 Δlogp  adv>0 +0.167   adv<0 -0.226   差 +0.392

|adv| 0.00~0.25   67.3%    |adv| 0.50~1.00   93.3%
|adv| 0.25~0.50   86.6%    |adv| 1.00 以上   95.4~95.9%
```

逐輪一致率最低 67.2%、中位 83.7%。**PPO optimization 本身正常**，
不必往 ratio / clipping / advantage handling 查。

### 93.2 advantage 對實際 outcome 的預測力

⚠️ `ret = adv + old_value`，拿它當 ground truth 是循環論證。實際 future
return 要從 `rew` 沿軌跡往後加（`gamma=1.0` 沒有折現，閉式解成立：
每條軌跡的 Σrew = 期末差額/10,000 + 勝負 bonus，16 條全部對得上）。

```
以軌跡為單位 corr(平均 adv, 最終 margin)   +0.9061   n=960
decision 為單位 corr(adv, 最終 margin)     +0.6486   ⚠️ 有效樣本是 960 不是 69 萬
corr(adv, 實際 future return)              +0.4824
對照 corr(ret, 實際 future return)         +0.9790

分桶 → 最終 margin（六桶完全單調）
< -1.0     -60,107      0.0~+0.5   -34,495
-1.0~-0.5  -47,087     +0.5~+1.0   -29,729
-0.5~ 0.0  -39,315     +1.0 以上   -25,231

adv>0 vs adv<0：實際 future return +1.16、最終 margin +12,315
```

### 93.3 「future return 不單調」是分桶造成的假象

```
corr(future return, 局內第幾步)   +0.5933   ← 越晚剩的越少，機械性的
corr(advantage,     局內第幾步)   -0.0025   ← advantage 跟時間無關
|advantage| 隨時間              0.644 → 0.301
```

把時間控制住之後（六個步區間內部各自分桶），**五個區間完全單調**，
只有第 600 步之後那一段在正端翻回來（剩不到 120 步、|adv| 只有 0.301）。

**結論：不該往 reward / credit assignment / value target 查。**

期末作物格 17.05 vs 23.75，空地率 46.1% vs 22.4%。**PLANT 只有對手的 43%。**

⚠️ 這不是 PPO 造成的：起點的 MOVE 佔比是 56.9%，200 輪後 57.0%，**沒動**。

老師 51.8%）。

### 94.1 走路多的原因：不是目標遠，也不是改主意

同一批盤面上，網路 vs gen0（用 g175 的參數當 oracle）：

```
到目標的平均距離     1.06     1.03      ← 一樣
距離分布 6+ 格       0.9%     1.7%      ← 我們反而更近
還沒到就換目標      33.3%    51.4%      ← gen0 比我們善變得多
```

**兩個假設都否定。** 拆解：

```
「還沒走到」的比例   網路 56.4%   gen0（在我們的盤面上）53.7%   g175（自己的盤面）45.6%
盤面造成的   53.7 − 45.6 = 8.1 個百分點（71%）
策略造成的   56.4 − 53.7 = 2.7 個百分點（24%）
```

**七成以上是「盤面長什麼樣」造成的，不是「怎麼選目標」。** 候選（都沒驗）：
田少→附近沒事做→走更遠→更沒時間種田的迴圈；買地晚 3.5 天（day 8.6 vs 5.1）。
