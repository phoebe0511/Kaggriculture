### 111.5 判定 C

理由跟 §105 對 F2 判 C 是同一條：**會計上是真的、拿掉也生效了，但量不到下游
改善。** 這裡的 t=0 對照比 §105 更乾淨。

要講清楚不符的地方：C 的字面條件寫「行為幾乎沒改善」，**行為那一半不符** ——

deployed 的 qty 行為跟起點沒有差別。B/C 的定義沒有涵蓋「行為改變是監督式先驗
解鎖的，不是 PPO 學的」這一格，按事先講好的 held-out greedy margin 歸到 C。

限制：單一一對 run；60 輪都在 plateau 內。

### 111.6 🩸 replay 一定要用跟訓練同一個 device

## §112 quantity × advantage：判定 C，learning signal 沒有壓制 quantity

### 112.1 既有 dump 沒有 `qty_idx`

### 112.4 qty=1 vs qty>1

```
                        init                          last
                 qty=1    qty>1      差        qty=1    qty>1      差
未來實際報酬 R    -4.5801  -4.8136  -0.2335     -4.6604  -4.7946  -0.1342

```

🩸 **advantage 的優勢完全來自 critic 的基準線，不是來自結果。** qty>1 的實際
未來報酬**比較低**，但 critic 把那些狀態壓得更低，相減之後 advantage 反而高。
-0.2335 -(-0.4054) = +0.1719，跟量到的 +0.1657 對得上（差額來自 lam=0.998
不是完整 MC）。未來報酬用 `rew` 沿軌跡後加，不用 `ret`（`model/ppo.py:450`）。

### 112.5 因果性：不能

advantage 的粒度是**一步**（整個聯合動作）。PICKUP 那一步平均有 8.29（init）／
8.44（last）個 unit 因子共用同一個 adv，其中約 49.7% 是 PICKUP。而且大數量的
PICKUP 系統性出現在比較早的步（軌跡內平均第 373.8 步 vs 406.7 步）。
112.2~112.4 全部只能當相關。

### 112.6 🩸 唯一能做因果宣稱的：把 qty 排除在 loss 外的對照

同一次 `ppo.update`（epochs 8、minibatch 512、target_kl 0.02、lr 3e-5、
ent_coef 0，同訓練），跑完再重算同一批觀測上的 π。單次量測有 CUDA backward
非確定性的噪音，所以做 5 對配對重複：

```
                          init                              last
                    mean      SE      t            mean      SE      t
ΔP(qty>1) 有 loss  +0.055pp  0.057   +0.98      +0.052pp  0.039   +1.33   n.s.
ΔP(qty>1) 對照     -0.698pp  0.028  -25.30      -0.361pp  0.031  -11.55
ΔP(qty>1) 淨signal +0.754pp  0.075  +10.09      +0.413pp  0.056   +7.36
```

**qty 自己的 learning signal 是在把數量往上推**（t=+10.09 / +7.36）。
把數量往下壓的是**共用軀幹的漂移** —— qty 不在 loss 裡時 π 每次更新往下掉
0.698pp / 0.361pp（t=-25.30 / -11.55）。qty head 是接在共用 trunk 上的線性層
（`model/net.py:100`），trunk 被 op / target / market / value loss 推動時它
跟著漂。**跟 §105 對 F2 記的同一個機制：「不在 loss 裡」不等於「不會動」。**

兩者相抵淨值 +0.055pp / +0.052pp，跟 0 分不開 —— 跟 60 輪實測 P(qty>1) 從
29.84% 掉到 25.83%（-4.01pp，約 -0.067pp/輪）同一個量級。

### 112.7 判定 C

沒有證據顯示 quantity 被 learning signal 特別壓制。三條獨立證據同向：
相關性方向就不對（112.2/112.3）、一階梯度推力對 q=9 是正的（init +13.4、
last +3.0）、直接量測是往上推（112.6）。

## §113 critic：判定 A，解析度不足以支撐 action ranking

### 113.1 資料來源：**沒有收新資料**

用訓練當下 `--dump-batch` 存的 120 個 npz（兩臂各 60 輪 × 11,504 步 /
16 條軌跡）。ground truth 用 `rew` 沿軌跡後加（gamma=1，就是未折扣尾和）。

管線驗證：算出來的「explained var vs GAE ret」是 0.8395 / 0.8198，跟
`train.jsonl` 的 0.83947 / 0.81975 對上。

### 113.2 V vs MC 報酬

```
                          qty-base    qty-on
MAE                        0.7215     0.8201
RMSE                       0.9816     1.1262
bias (V-R)                +0.0377    +0.0483
Pearson(V,R)              +0.8566    +0.8408
Spearman(V,R)             +0.8338    +0.8251
explained var vs MC 報酬   +0.7284    +0.6999
explained var vs GAE ret  +0.8395    +0.8198   <- train.jsonl 報的是這個
R 的 sd                     1.8164     2.0034
```

🩸 **`explained_var` 0.82~0.84 是對 GAE 目標算的，而 GAE 目標本身含 value。**
對 MC 報酬只有 0.70~0.73。bias 幾乎是 0，問題不在整體偏移。

### 113.3 「同 observation 多 action」做不到

rollout 裡每個 observation 只出現一次、只抽一個聯合動作，沒有同狀態的第二個
動作可比。兩個代用：

```
(a) 同 timestep、跨同一輪的 16 條軌跡      qty-base   qty-on
    桶內 Spearman(V,R)                    +0.4972   +0.4637
    桶內 P(Spearman>0)                     89.2%     91.1%
    桶內 |V-R| / 桶內 R 的 sd                0.69      0.71

(b) 軌跡內相鄰步（動作的效果就落在這一步）
    ΔV vs ΔR  Pearson                     +0.5198   +0.4233
    ΔV vs ΔR  Spearman                    +0.1793   +0.1510
    ΔV 的 sd                                0.1954    0.2152
    ΔR 的 sd                                0.1198    0.1217
```

🩸 **critic 逐步的抖動比實際逐步變化大 1.6~1.8 倍，秩相關只有 0.15~0.18。**
在「一步」這個尺度 —— 動作被選擇的尺度 —— critic 的移動主要是它自己的誤差。
（`ΔR` 恰好等於 `-rew`，所以它的 sd 就是逐步 reward 的 sd 0.128，兩處對得上。
「同號 44.6%」不要單獨解讀，`rew` 分布不對稱把這個統計量拖偏了。）

### 113.4 分段：問題集中在開局

```
qty-base           MAE    RMSE   r(V,R)   r(adv,R)      qty-on 的形狀一樣
early  0-239    0.9830  1.2543  +0.3858   +0.8263       early r(V,R) +0.3785
mid  240-479    0.7429  0.9682  +0.7214   +0.5989       mid        +0.7155
late  480-719   0.4374  0.5996  +0.8858   +0.3923       late       +0.8797
```

early 的 r(V,R) 只有 0.38、late 是 0.88。r(adv,R) 剛好反過來（early 0.83、
late 0.39）—— 開局的 advantage 幾乎就等於「這局最後怎麼樣」，因為 V 在那裡
解釋不了東西。開局的動作是被整局結果推的。

### 113.5 尺度與拆解

```
                              qty-base   qty-on
advantage sd                   0.6849    0.7809
critic error (V-R) RMSE        0.9816    1.1262
逐步 reward 的 sd               0.1284    0.1283
RMSE / 逐步 reward sd            7.6x      8.8x
corr(adv, -(V-R))             +0.9533   +0.9585

Var(adv) 拆三塊（三項合 97.8%，差額是移動平均的邊界效應）
軌跡平均（哪一局）              49.9%  sd 0.4836   49.2%  sd 0.5477
軌跡內慢速（±10 步移動平均）     41.9%  sd 0.4435   42.1%  sd 0.5069
逐步殘差（分得開相鄰動作的）      6.0%  sd 0.1676    6.4%  sd 0.1975

軌跡內 advantage 自相關 lag1 +0.973 lag5 +0.936 lag20 +0.879
                        lag100 +0.715 lag300 +0.402
積分自相關時間 365 步（約半局）
有效獨立 advantage 值：每輪 32 個（原始 11,504 步）
```

🩸 一個動作拿到的 advantage，**92% 的變異來自「這一局／這一段整體相對 critic
的估計如何」，只有 6% 來自能分辨相鄰動作的成分**（非鑑別 sd 0.656 對鑑別
0.168，約 4:1）。每輪 11,504 步、約 108,000 個 unit 因子的更新，背後只有約
**32 個**有效獨立的 advantage 數值。

`corr(adv, -(V-R)) = +0.95` 本身不是病徵 —— gamma=1、lam=0.998 之下
`A ≈ R - V` 是定義使然。病徵是尺度：V 的工作是把共有的未來減掉讓剩下的反映
這個動作，它的 RMSE 是逐步 reward 尺度的 7.6~8.8 倍。

### 113.6 判定 A，以及兩個必要的限制

有證據顯示 critic 解析度不足以支撐 action ranking（113.3 的 1.6~1.8 倍與
0.69~0.71、113.5 的 7.6~8.8 倍與 6%、112.4 那個方向相反的具體案例）。

限制一：**分不出是 critic 還是 advantage estimator。** `gamma=1.0 /
lam=0.998 / 720 步`之下 `A ≈ R - V`，相鄰兩步的 R 只差一步的 reward，所以
除非 V 幾乎完美，advantage 本來就會高度自相關。要修的可能是 gamma / lam /
baseline，也可能是 critic 本身，這份資料分不出來。

限制二：`explained_var` 0.82~0.84 沒有錯，只是量錯東西 —— 對 GAE 目標算、
而且是整批的解釋力，跟「同一步不同動作之間分不分得開」是不同的問題。

## §115 critic 的「不看盤面」下界

### 115.1 🩸 §114 批准的那個實驗做不了

cum_rew(t)·t]`，全部在 t 時刻可見。target 一律用沿軌跡後加的 MC future
reward（gamma=1），切分以**軌跡**為單位。

## §116 residual advantage 有沒有 action-level signal：判定 B

### 116.1 定義

960 條軌跡 / 690,240 步（比 §113 大）。分解對每條軌跡各自做：

```
adv = m_j（軌跡平均） + slow_j(t)（MA_21 的軌跡內慢速） + resid_j(t)（逐步殘差）
```

MA_21 是**置中、邊界縮窗**的移動平均。`critic3.py` 那版用
`np.convolve(mode="same")` 零填充，會在頭尾 10 步把殘差灌大，這裡修掉了 ——
所以 §113.5 的 49.9/41.9/6.0 跟這裡的數字有落差，兩邊都沒錯。

action-level ground truth（主定義）：

```
R_resid[t] = fr[t] − mean_j(fr) − MA_21(fr − mean_j(fr))
```

對 adv 與 fr 施加**完全相同**的線性濾波，沒有 leakage（只由實際 reward 造出
來，不含 V 或 adv）。對照定義 `cent_rew[t] = rew[t] − mean_j(rew)`。

🩸 限制：`fr[t] − fr[t+1] = rew[t]`，所以 fr 的高頻段主要是逐步 reward 的起伏。
這個檢定測得到「立即結果」；**純延遲**的動作效果落在慢速段，用觀測資料跟狀態
效果分不開。

### 116.4 下一步優先查 advantage estimator，不是 critic

92/6 這個比例用設定就能算出來，不需要假設 critic 有問題。實際命令是

加權 `(γλ)^k`，等效視窗 `1/(1−0.998) = 500` 步，一局 720 步。§113.5 量到
lag1 +0.973、積分自相關時間 365 步，跟這個量級一致。

真正的視窗是 500 步。**help 的數字對這個設定不適用。**
