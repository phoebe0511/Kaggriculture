## §49 structure_spread：**已證偽**，但過程比結論有價值

### 49.1 起點：使用者的觀察

「ladder 上贏我們的，大多是種滿格子的」「他們的動物屋在中心，第二塊的中心
也會有」「我們動物都在第一塊地裡」。三個都在資料裡查證了。

八個對手的建物分佈（1,280 局期末）：

```
              NW    NE    SW   集中度
我們         11.9   0.0   0.0   100.0%   <- 1,280 局全部如此
recursion     6.0   7.0   0.0    53.9%   他贏我們 98%
utkarsh       5.9   5.9   2.0    42.8%   他贏我們 88%
其餘六個     ~5.9  ~6.0  ~2.0    ~43%
```

根源在 `agents/gen0.py:337` 的 `structure_tiles`：兩層迴圈都是 `range(half)`，
只掃 NW，而且簽章只吃 `(board, n)`，**收不到解鎖狀態**，結構上不可能放到別處。
就在下面 30 行 `active_crop_tiles` 的註解寫著「round-robin，而不是先塞滿 NW
再輪到 NE/SW/SE」—— **作物早就修過同一個問題，動物沒修。**

相關性（n=8 個對手）：作物佔用 vs 贏我們的比率 r=+0.780；
生產動作佔比 vs 贏我們的比率 r=+0.837。我們的生產動作佔比 33.7% 是全場最低，
MOVE 佔比 57.5% 是全場最高。

### 49.3 介入完全生效，方向全對，結果更差

我預先講的機制是「建物分散 -> 少走路 -> 生產動作變多」。**三個指標全部照預期
移動：**

```
             MOVE%    生產%    作物佔用
基準線       57.5%    33.7%    0.500
sp50         56.4%    35.3%    0.550
sp67         56.4%    34.6%    0.539
sp100        54.8%     --      0.568
```

而且產出也全面上升：PLANT +14.3、HARVEST +20.4、WATER +72.7、FERTILIZE +7.9。
**然後現金掉了 3,206。**

我先猜是建物蓋得太晚（NE/SW 要等第 6/10 天才解鎖），用
`structure_tile_turns / 期末建物` 驗 —— 601 vs 605 vs 600 回合，**猜錯了**，
建物存在的時間幾乎一樣。

真正動的是**單位收入**：

```
             HARVEST   現金/收成
基準線          354       218
sp50            375       198     多收 6%，每次少賺 9.2%
```

### 49.4 兩次失敗有同一個模式

```
seed_backlog（§46）  作物佔用 0.500 -> 0.554   現金 -10,135
structure_spread     收成      354  -> 375     現金  -3,206
```

**兩次都是提高產量，兩次現金都下降。瓶頸不是產量，是每單位的收入。**

對手那份相關性要重讀：他們作物佔用高**而且**現金高，但我們把佔用拉高就變窮
—— 所以佔用是他們「賣得好」的**結果**，不是現金的原因。相關係數 +0.780
完全沒有預測到介入的方向。

### 49.5 🔴 市場耦合是量到的，不是推論

sp100 是這批裡最有價值的一組：

```
我方現金  -1,072（雜訊內，t 不顯著）
對手現金 +11,158
差額     -12,230  t=-17.4
```

**我們只改了自己建物的位置，對手多賺了 11,158。** 兩邊共用市場，我方的產銷
改變會經由價格直接改動對手的期末現金。

### 49.6 🔴 這件事直接打到 PPO 的 reward 設計

§37 把 reward 從零和改成只看自己的現金，理由是「對手那一項佔 86.4% 的變異數
而且我們控制不了」。**「控制不了」這個前提是錯的** —— sp100 證明我方的行為
可以讓對手的現金動 11,158。

後果很具體：一個只看自己現金的 PPO，會把 sp100 這種改動評為**幾乎中性**
（−1,072），但它實際上把勝率從 24.1% 砍到 11.7%。

所以現在的取捨是：

```
零和 reward    正確，但 86.4% 的變異數來自對手     -> 訊噪比差
own-cash       低變異數，但對「幫到對手」的改動盲目 -> 有系統性偏誤
```

兩個都有問題，**還沒有驗過的第三條路**。這是目前 PPO 最該解決的設計問題，
比再多跑幾輪重要。

### 49.7 程式

`structure_tiles(board, n, spread=0.0)`，`spread=0` 逐項等同舊實作（測試裡把
舊碼抄了一份當對照，n=1,2,6,11,12,20,25 都驗）。順序只由 `board/n/spread` 決定，
收不到解鎖狀態，所以買地不會讓已蓋好的建物換索引 —— 用 `inspect.signature`
把這個結構性保證釘住。

🩸 寫測試時我原本斷言「n 變大時前綴不變」，`spread=0.5` 掛掉。**是我斷言錯了**
—— NW 配額是 `n` 的比例，前綴性質不成立，而且也不需要成立（一局之內 `n` 不變）。
改成驗真正需要的純函式性質。

`structure_spread` 故意不進 `DEFAULT_PARAMS`（§46 的 tripwire）。
161 項測試通過。commit `187aa86`。

**出貨版不動，仍是 `cma1-g50-wt`（24.1%）。**

## §50 換老師有效；PPO 從好起點反而變差

### 50.1 換老師：+11.3pp，比 300 輪 PPO 更有效也更便宜

hybrid（gen0 出工人、網路出 market），各 1,280 局同 seed 可配對：

```
                                  ladder    配對現金差 vs gen0      成本
round6 market（gen1 老師）          2.8%    -19,424  t=-24.5       --
  + 300 輪 PPO                     10.0%     -8,021  t= -9.8      3 小時 GPU
  + 換 cma1-g50-wt 老師            14.1%     -9,391  t=-13.9      14 分 + 1 小時
cma1-g50-wt（gen0 本身）           24.1%        --                出貨中
```

老師從 `gen1`（ladder 3.0%）換成 `cma1-g50-wt`（24.1%）：**+11.3pp，比 300 輪
PPO 的 +7.2pp 更多、時間少一半。** 使用者提的方向成立。

但 14.1% 仍低於 24.1%。純模仿追不上老師是預期的（target 準確率 0.8404 會累乘）。

### 50.2 🔴 PPO 從好起點會把策略打壞

同樣的設定，只換起點（`ckpt-cma1-round0-tgt` 取代 round6）：

```
區間        取樣現金   entropy    greedy
0-10         61,455     1.309    77,628   <- best.pt 停在第 10 輪
10-50        37,436     1.524   ~38,000   <- 頭幾十輪直接崩掉

**`best.pt` 是第 10 輪存的，之後 290 輪沒有一次超過它。**

entropy 一路從 1.309 升到 2.152。`--ent-coef 0`，沒有任何項在推高它 ——
是策略被推離原本確定而正確的行為。

### 50.3 這讓 §48 的結論要重新解讀

§48 我寫「PPO 確實有效，+11,402，t=+14.6」。那一次起點很差（round6 market，
2.8%），PPO 爬了一段。這一次起點好（14.1%），PPO 先打壞再往回爬。

兩次是同一個形狀：**先掉、再回復**。差別只在起點差的時候「回復」能超過起點，
起點好的時候不能。

所以更一致的解讀是：**那 +11,402 是回復，不是進步。** 我沒有辦法只用這兩次
就完全確定，但「起點越好、PPO 收益越少甚至為負」這件事是量到的。

六次 PPO 至今**沒有一次讓好策略變得更好**：

```
