### 117.3 🩸 phased λ 的語意不是「前段 500 步視窗」

λ 逐步作用在 carry 上，所以第 0 步看到第 k 步的權重是 `∏λ`。前 240 步用 0.998、
之後 0.95，代表第 0 步看到第 240 步（收穫）的權重是 `0.998^240 = 0.619`，
**再往後以 0.95 衰減、約 20 步就沒了**。實際語意是「早期動作看得到收穫，但看不到
收穫之後的長尾」。

### 117.6 🩸 critic 沒有變好，train.jsonl 的 explained_var 是定義造成的

```
                              qty-base   lam-split       差
explained_var (train.jsonl)     0.8395     0.9578   +0.1184
explained var vs MC 報酬         0.7284     0.7246   -0.0038   <- 真正的
RMSE vs MC                     0.9816     0.9481   -0.0335
Pearson vs MC                  0.8566     0.8525   -0.0041
value loss                     0.3754     0.0877   -0.2877
```

`ppo.py:497` 是 `1 − Var(ret−value)/Var(ret)`，而 `ppo.py:88` 的
`ret = adv + value`，所以 `ret − value` **恆等於** `adv`：

```
explained_var ≡ 1 − Var(adv) / Var(ret)
```

降 λ 必然縮小 `Var(adv)`（sd 0.7039 -> 0.3117），explained_var 和 value loss 的
改善**全部是定義造成的**。用 MC future reward 重算，critic 幾乎沒動。

好消息：這也排除了「critic 撐不住較低 λ」的疑慮 —— 那個檢查只在 treatment
變差時才需要，這裡不適用。

### 117.7 判定 A，以及三個限制

learning signal 四項全部改善、held-out greedy margin 也改善（t 檢定 p=0.035、
符號檢定 p=0.039，兩個都過 0.05）。不是 B（margin 有改善）、不是 C（兩者都改善）。

不判 D（「噪音太大不足以判定」）的理由：兩個獨立檢定都過 0.05，配對差沒有正
自相關。但下面三條削弱這個結論：

**一、只有一對 run。** 12 個評估點是**同一條訓練軌跡**上的 12 個 checkpoint，
不是 12 次獨立重跑。t 檢定回答的是「這一對 run 之間差異穩定嗎」，不是「重跑一次
還會這樣嗎」。§105.3 量到同設定重跑第 1 輪就差 7,347，那個層級的變異這個檢定
量不到。

**二、baseline 是 09-08 跑的，不是新的。** code 相同（無 commit、working tree
乾淨），但 GPU driver / torch 版本查不到當時的狀態。

**三、成分拆解有窗寬 confound。** `MA_21`（±10 步）是為 λ=0.998 挑的，而
treatment 的等效視窗就是 20 步，同尺度。「殘差佔比 5.51% -> 16.70%」有一部分是
分解器的假影。R_resid 的比較受影響較小（同一個濾波器同時作用在 adv 和 ground
truth 上），但兩臂的濾波器與各自 estimator 時間尺度的關係並不相同。

## §118 三條方法上的陷阱

```
1  explained_var ≡ 1 − Var(adv)/Var(ret)（見 117.6）。任何縮小 Var(adv) 的改動
   都會讓它上升。要判斷 critic 好壞一律用 MC future reward 當 target 重算，
   比較基準是 §113.2 的 0.7284 / 0.6999。

2  同一組統計量有「逐輪算再平均」與「全部合併」兩種算法，§113.2 用的是**逐輪
   算再平均**（八項全部逐位對上）。MAE 和 bias 是均值，兩種相同；RMSE / 相關
   係數 / sd / explained_var 是非線性的，兩種不同（qty-base：RMSE 0.9816 vs
   1.0179、ev_mc 0.7284 vs 0.7006）。跨 journal 比數字前先確認是哪一種。

3  MA_21 的邊界：`critic3.py` 用 np.convolve(mode="same") 零填充，會在頭尾
   10 步把殘差灌大；`resid_signal.py` / `lam_diag.py` 用置中縮窗。§113.5 的
   49.9/41.9/6.0 與縮窗版的 49.85/42.65/5.82 落差來自這裡，兩邊都沒錯。
```
